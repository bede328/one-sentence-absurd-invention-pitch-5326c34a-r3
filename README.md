# One-Sentence Absurd Invention Pitch — Round 3

Entry for the [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) competition on make.fun.

A single sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: a phone charger that only charges while you squat, so a dead battery and never exercising are solved by the same absurd mechanism — and both run out at exactly the same time.

## Run it: node main.ts

Requires Node 22.18 or later. The program is deterministic, uses no network and no secrets, and writes the pitch to `/output/entry.txt`.
